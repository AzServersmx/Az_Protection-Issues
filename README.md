# Az_Protection 1.0.0

**Protege tus construcciones con estandartes especiales.**

Az_Protection es un plugin de protección de terrenos para servidores de Minecraft. Permite crear regiones protegidas al colocar estandartes especiales y visualizar sus límites directamente en el juego.

## Características

- Seis niveles de protección, desde 8 × 8 hasta 256 × 256 bloques.
- Creación de regiones protegidas mediante WorldGuard.
- Visualización del perímetro con partículas verdes al hacer clic derecho en el estandarte.
- Retirada de la protección al romper el estandarte por su propietario o un administrador.
- Prevención de colocaciones que se superpongan con regiones existentes.

## Niveles de protección

| Nivel | Área |
| --- | --- |
| Inicial | 8 × 8 |
| Común | 16 × 16 |
| Especial | 32 × 32 |
| Raro | 64 × 64 |
| Épico | 128 × 128 |
| Leyenda | 256 × 256 |

## Instalación y documentación

Requiere un servidor Paper compatible, Java 25, WorldEdit y WorldGuard.

Consulta la [guía de instalación y uso](docs/README.md) y la [Wiki](https://github.com/AzServersmx/Az_Protection-Issues/wiki).
