# Az_Protection — Soporte oficial

Repositorio público de soporte para **Az_Protection 1.0.0**, plugin de protección de terrenos de AZ Servers.

## Soporte

Utiliza la pestaña **Issues** para reportar errores o proponer mejoras. Incluye versión de Paper, Java, WorldGuard, WorldEdit, pasos para reproducir el problema y registros pertinentes (sin información privada).

## Documentación

La documentación de instalación, comandos, permisos y uso se publicará en la **Wiki** de este repositorio.

## Distribución y código fuente

El código fuente de Az_Protection es privado. Este repositorio no es el repositorio del código del plugin. El software es propietario; consulta los términos de la licencia oficial.
